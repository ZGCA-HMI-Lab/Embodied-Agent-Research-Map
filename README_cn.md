# 具身动作模型研究地图

**面向机器人动作生成与控制的学习式模型双语研究地图**

[English](README.md)

</div>

本项目整理根据环境观测、机器人状态及任务目标或指令，预测或生成机器人可执行动作的学习式模型，关联研究问题、动作表示、模型结构、学习方式、数据与泛化证据。

初始地图包含三个研究板块：操作、导航、身体运动与全身控制。板块之间允许交叉，每篇论文选择一个主要分类，并可标注相关板块。后续结合代表论文逐步细分分类。

**当前状态：** 已建立初始研究范围和分类结构，尚未收录论文、数据集或工具条目。

## 研究范围

核心收录对象是为真实或仿真机器人输出可执行动作、动作序列或运动轨迹的学习式策略与动作模型。相关输出包括末端位姿、关节目标、底盘速度和力矩。

感知、人类动作数据、世界模型、仿真与传统控制可以作为基础资料收录，但应说明其与机器人动作生成或执行的联系。单独的纯感知或视频生成工作不属于核心收录范围。

## 研究地图

双语分类数据源为 [`taxonomy.json`](taxonomy.json)。当前每个板块作为末端分类，使用唯一分类码。点击图片可查看原尺寸。

[![具身动作模型研究地图](mindmap_cn.svg)](mindmap_cn.svg)

| 分类码 | 研究板块 | 核心问题 |
|---|---|---|
| `AM.MAN` | 操作动作模型 | 如何生成改变物体状态的机器人动作？ |
| `AM.NAV` | 导航动作模型 | 如何生成到达目标位置或寻找目标的移动决策与轨迹？ |
| `AM.WBC` | 身体运动与全身控制模型 | 如何生成、跟踪身体动作，维持平衡并协调多个身体部位？ |

第一层按研究问题组织。机器人形态、输入输出、模型结构、动作生成方式和学习方式作为独立属性，在阅读论文时分别记录。

## 按研究板块整理论文

论文编号由分类码和稳定序号组成，例如 `AM.MAN.1`。序号用于识别论文，不表示排名。每个条目记录论文、一句话概括、发表信息、可用资源，以及适用时的相关板块分类码。

### 操作动作模型 [`AM.MAN`]

包括抓取、放置、装配、灵巧操作和双臂操作。移动操作以完成物体交互为主要研究问题时归入本类，并可关联导航或全身控制板块。

| 编号 | 论文 | TL;DR（一句话） | 发表 / 年份 | 资源 | 相关板块 |
|---|---|---|---|---|---|

### 导航动作模型 [`AM.NAV`]

包括点目标导航、物体目标导航、语言导航、探索与导航轨迹生成。重点是利用环境观测到达或找到目标；涉及行走执行时，可关联身体运动与全身控制板块。

| 编号 | 论文 | TL;DR（一句话） | 发表 / 年份 | 资源 | 相关板块 |
|---|---|---|---|---|---|

### 身体运动与全身控制模型 [`AM.WBC`]

包括行走、平衡、动作跟踪、起身、复杂运动技能与身体协同控制。行走操作以身体协同、平衡或动作执行为主要研究问题时归入本类，并可关联操作板块。

| 编号 | 论文 | TL;DR（一句话） | 发表 / 年份 | 资源 | 相关板块 |
|---|---|---|---|---|---|

## 维护与贡献

新增内容时同步维护两种语言。修改分类时编辑 [`taxonomy.json`](taxonomy.json)，再重新生成导图：

```bash
python3 scripts/build_mindmap.py
python3 scripts/build_mindmap.py --check
```

收录标准、分类边界、论文编号与贡献步骤见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。生成脚本仅使用 Python 3 标准库。
