# InternW0：一份论文记录、两个分类入口

状态：用户已于 2026-11-04 确认实施，标签按后续确认采用 WAM架构、AE侧触觉输入（均加粗）、动作—接触联合预测。实现与验收记录见同日期 implementation plan。

## 目的与范围

用户已认可异步 WAM 方向，同时希望在当前重点阅读的触觉方向看到 InternW0 的接触感知后训练。目录、静态思维导图、网页分类时间地图与可聚焦树都应提供两个入口；后续事实更新仍只维护一个论文 JSON。

## 方案选择

- 推荐：一份规范记录，加一个显式的额外展示入口。两处展示共用稳定 id、slug、原文、作者、时间、来源和评测事实，可提供不同侧重的短摘要与展示标签。全库论文列表、检索、主题、导出与论文总数按 id 去重。
- 沿用 related_categories：当前只能生成相关文档链接，树和网页没有第二个节点，不能满足本次需求。
- 两份论文 JSON：会产生双份事实和重复计数，不采用。

这是对展示接口的可选扩展，不把所有历史 related_categories 自动转成重复节点。当前仅对 InternW0 启用。

## 分类与两处内容

主分类建议设在当前重点研究的触觉方向：

```text
操作动作模型
├─ 多指灵巧手操作研究
│  └─ 触觉操作
│     └─ 后训练 [AM.MAN.DEX.TACTILE.POSTTRAIN]
│        └─ InternW0
└─ 共性方法
   └─ 异步WAM架构 [AM.MAN.METHOD.ASYNCWAM]
      └─ InternW0（同一论文的另一个入口）
```

仅新增这两个末端分类。保留 Spark-0、FACT、AgenticTactileVLA 及其他已收录论文的现有归属。

触觉后训练入口的简介：InternW0 在预训练 WAM 的动作专家侧加入已观测的力／触觉历史，用流匹配联合去噪未来动作与接触信号，再将动作通道解码执行，使后续动作结合接触反馈生成。

触觉标签（按顺序）：**WAM架构**、**AE侧触觉输入**、动作—接触联合预测。前两项均使用 bold: true；三个标签分别表达整体架构、触觉输入位置与联合预测目标。“触觉后训练”由分类路径体现，不再占用展示标签。AE 明确指 Action Expert（动作专家）；其实际输入为生成动作前已观测的力／触觉历史，不能将其表述为 VLM 侧输入或自编码器。

异步 WAM 入口的简介：InternW0 将慢速视频预测与快速动作生成异步解耦，用最新图像通过 K/V 编辑器修正缓存预测上下文，供动作专家生成下一段动作，减少每次动作更新所需的视频重计算。

异步标签：**异步WAM架构**、观测条件K/V编辑、跨操作平台。

正文边界：异构预训练本身不要求力或触觉标注；这些通道在接触感知后训练中引入。未来接触是联合预测目标，只有生成前已观测的历史可作输入；文中明确动作通道用于执行，不把预测接触信号擅自表述为直接下发的力控目标。异步路由设计承接 AHA-WAM，不能全部表述为首次提出。双夹爪和多指手均有实验，任务不同，不能宣称同一任务直接跨手迁移。

## 接口与显示规则

- 保留现有 category 作为主分类；新增可选 additional_entries 数组，每项包含一个已定义末端 category，以及双语 tldr 和最多三个双语 display_tags。额外入口与主分类不能相同，各额外入口不能重复。
- 额外入口只覆盖该分类下的简介与可见标签，不得覆盖作者、资源、日期、评测、benchmark 或编号。唯一论文记录仍在 data/papers/internw0.json。
- related_categories 保持现有文档关联语义；不隐式启用额外展示，不为旧记录增设节点。
- 目录、首页入口表和两种树按显式入口显示；每处节点仍打开同一论文。网页详情标明主分类与另一个展示入口，可查看两个侧重的简介。
- 分类筛选在主分类和额外入口中均能找到该论文；列表、搜索、主题、详情上下篇和 JSON/CSV 每篇仅出现一次。分类条目按该类成员计数，父类和全库按稳定 id 去重，不能把两个入口误算成两篇论文。
- 树节点使用“分类码＋论文 slug”区分展示节点；研究记录仍使用原 id 和 slug。图片导出包含当前子树下的入口，完整总图允许在两个分类各显示一次。
- 在同一 JSON 内修改共享事实或分类入口后，运行 build_catalog.py 同步全部生成物。不得在网页或静态 SVG 中硬编码 InternW0。
- 文档标明“论文总数为去重计数，分类数之和可能大于论文总数”。旧记录缺少 additional_entries 时行为完全不变。

## 验收

- 新增一篇后全库从 67 篇变为 68 篇，不是 69 篇；分类从 19 个变为 21 个。
- InternW0 在两个新目录和静态／网页分类树各有一个入口；分别聚焦两个分类均能查到，聚焦共同父类列表仅一篇。
- 两个入口显示各自双语标签和简介，打开相同论文、共享事实与资源；AgenticTactileVLA 等已有记录不变。
- Python 结构校验覆盖无效分类、重复入口、摘要和标签格式；Node 测试覆盖双入口筛选、父级去重、树节点身份及唯一 JSON/CSV 导出。
- 完成统一构建、生成一致性、Python/Node 测试和 git diff --check；浏览器核对两个分类、列表去重、双语详情、筛选、子树图片导出及窄屏。
- 更新 AGENTS.md、CONTRIBUTING.md、scope 双语说明和 interactive-map.md，明确后续模型只编辑规范记录。
