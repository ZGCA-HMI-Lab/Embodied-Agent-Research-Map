# 可聚焦的网页思维导图

新增“思维导图”视图，与分类时间地图和论文列表并列。点击任意分类，以该分类作为根重新布局，只展示其全部后代分类及匹配论文；分类默认全部展开。路径导航、返回上级、返回总览和分享链接支持逐级浏览。当前层子分类提供快捷按钮，避免在长树中滚动寻找下钻入口。论文保留展示标签、原文链接和现有简介对话框。

## 方案与边界

选择网页即时构树与导出，而非预生成每类静态子图：复用 taxonomy、单篇 JSON、筛选和详情，不增加数据源、依赖或服务。网页和 SVG／PNG 导出共享绘图逻辑，减少后续维护分歧。保留现有静态 SVG、地图和列表。默认入口不变；树形视图共用当前筛选，明确提示筛选影响，代表作开关继续有效。

## 实现约定

原生 SVG 文本节点与连线，按当前语言计算紧凑尺寸；当前根的完整分支按高度向两侧平衡分配，各侧保留分类顺序。根位于中央，切换范围将视窗对准新根。画布内部滚动，支持缩放、100% 和适应全图。网页与 SVG／PNG 图片导出使用相同布局和文本渲染，不导出截图。所有分类展开；分类叶下展示全部匹配论文，空类明确标识。只使用显式 category 和既有分类标识，相关分类不复制论文。分享新增 view=tree，复用 category/lang/筛选参数；失效分类保持安全回退。分类范围变化将画布视窗对准新根，详情关闭恢复触发按钮焦点。语言切换、深色模式、窄屏、离线页面均可用。

## 验收

测试锁定紧凑高度、双侧无重叠布局、当前语言换行、完整独立 SVG／链接／加粗标签及 PNG 资源上限；同时锁定子树范围、空类与筛选零结果、历史 ID 不影响归类、唯一论文节点、布局不重叠及 tree 分享状态。统一构建＋Python/Node 检查；浏览器检查聚焦/上级/总览、前进返回、筛选、详情、双语、移动端、深色和本地离线。数据与分类源文件保持不变。提交、推送和部署依本次任务授权执行；实际验证状态记录在实现文档中。
