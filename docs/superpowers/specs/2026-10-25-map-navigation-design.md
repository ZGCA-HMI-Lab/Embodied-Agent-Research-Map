## 当前问题与证据

2026-10-25 在 Chrome 对照线上页面和参考页面，并检查 web/ 实现：

- 当前首屏的大标题、说明和筛选面板占用较多空间，分类图出现在页面下半部。
- app.js 默认展开所有中间节点；展开父节点仍各占一个空白表格行，深层分类被推到下方。
- 每篇论文使用完整卡片。同月同类的多篇论文垂直堆叠，使一行过高。
- 分类颜色仅有统一背景；论文边线按成果类型着色，不能直观看出研究分支。
- 有主题、类型和时间筛选，但没有研究分类聚焦、列表浏览、分享筛选状态或导出。
- 已核对 site/map.json 的 taxonomy 与 taxonomy.json 完全相等；19 篇工作按显式 category 归类。问题在呈现层，现有研究分类不迁移。

参考页面实际使用默认收起的大类、分支颜色、每格少量论文与 +N 展开、较紧凑的标题栏及时间导航；展开后显示子类。

## 方案选择

建议：在现有无依赖静态页面上增加紧凑地图和论文列表，共享筛选状态与唯一数据源。用户已选择保留研究分类；具体交互设计由本方案提出。

替代方案：迁入完整的文献管理框架。可获得更多现成功能，但需要重新适配双语摘要、benchmark 五项字段、离线打开与构建接口。现阶段不采用。

## 本轮功能范围

1. **紧凑分类地图**：压缩页头和筛选区，默认展示大类聚合；分类分支有稳定颜色、层级缩进和计数，可逐级展开、全部展开或返回总览。展开的父级使用紧凑分隔行。分类说明可从当前 taxonomy 中查看。空分类保留明确状态。
2. **紧凑论文条目**：每格默认最多三篇，其余显示“还有 N 篇”，可展开和收起。保留三项可见方法／主题标签，标题直接跳转论文，独立详情入口支持键盘和触屏。预览按公开时间排序，不把排序解释为质量或代表性。
3. **分类与时间导航**：增加研究分类聚焦，支持父类及其后代、返回全部；保留主题交集和类型筛选。增加时间横向导航、清楚的当前筛选状态及逐项清除。日期仍沿用现有证据和精度。
4. **论文列表视图**：与地图共用分类、主题、类型、时间和搜索条件，支持最新／最早／名称排序，展示分类路径、方法标签和摘要；长列表分批显示。窄屏优先使用列表，仍可切换地图。
5. **详情与分享**：详情复用已有双语字段和 benchmark 五项说明，增加当前结果中的上／下一篇、返回所在分类，以及复制单篇链接。URL 可恢复筛选、视图和论文详情；未知参数安全回退，不导致空白页面。浏览器返回／前进恢复状态。
6. **结果复用**：导出当前筛选结果为 JSON 或 CSV，字段包含论文链接、分类、标签和摘要。JSON 保留完整事实，CSV 以当前语言输出常用列。导出范围与结果计数一致，并处理表格公式前缀。

本轮不建立新的论文事实库、自动引用关系或账号系统。引用连线仍需要独立、可核查的关系证据。

## 数据与维护约定

- taxonomy.json、data/papers/*.json 和 data/topics.json 继续为唯一数据源；不改变论文 ID、slug 或 category。
- web/ 维护视图，build_catalog.py 统一生成目录、SVG 和 site/；不手改生成文件。
- 视图筛选、排序、折叠、主题、语言等状态属于页面状态，不写回研究记录。
- 分类数量表示匹配的论文数量；同一篇论文在同一视图只计一次。
- 分享参数不包含论文全文或个人笔记。单篇链接使用稳定 slug；分类参数必须经当前分类树验证，失效时显示全部。
- 单篇链接优先保证有效论文可读：若该论文被当前筛选或默认时间范围排除，仍打开详情，提示其不在当前结果中；此时不提供误导性的结果内上／下一篇，保留返回结果入口。
- 父类没有分类码，分享时以英文名称与排序后的后代末端分类码集合标识（区分后代相同的单子节点层级）并核对当前树，不使用 /0/1 等数组位置。层级发生变化而无法精确匹配时回退全部并给出提示，不能静默定位到另一分类。
- 分类计数明确区分匹配数与全库数；全库为零显示“尚未收录”，筛选后为零显示“当前条件无匹配”。
- 更新 docs/interactive-map.md 和 CONTRIBUTING.md，明确新增页面功能、URL 与导出约定，以及 agent 的生成和验收流程。

## 验收

- 所有 19 篇现有论文、12 个末端分类和双语事实保留；与 SVG 使用同一分类树。
- 桌面首屏能够直接看见主要分类；折叠时可看聚合论文，逐级展开可达全部条目。
- VLA 与触觉交集、分类与主题交集、无结果、空分类、仅代表作及重置均可用。
- 搜索结果能直接读摘要；列表排序不把仅有月份的记录伪造为具体日期。
- 单篇分享、筛选分享、返回／前进、上／下一篇和导出与当前结果一致。
- 中英文、深浅主题、键盘操作、窄屏和离线打开验证通过。
- 新增覆盖分类筛选、预览溢出、URL 恢复和导出的行为测试；执行现有 Python/Node 测试、统一构建及 --check、git diff --check。
- 推送部署作为单独发布步骤，发布后核对 Actions 和线上实际数据、交互。
