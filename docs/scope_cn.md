# 研究范围与分类边界

[首页](../README_cn.md) · [比较笔记](../notes/latency-review_cn.md)

## 研究问题

收录范围为 VLA / WAM 真机延迟优化：单次计算成本、历史条件下的动作生成、观测过时、异步执行与动作时间粒度。主要问题是：何时刷新感知、生成需要多少计算、预测结果何时真正执行，以及这些决策怎样影响闭环成功率。

分类依据是所解决的瓶颈，不按手型重新铺开整个具身领域。基座论文用于解释计算路径，不自动计入专门加速方法。

## 分类规则

- 感知与 VLM 复用：token 筛选、特征/上下文复用；ElegantVLA 横跨 AE 调度，以 related_categories 关联。
- 一步生成与蒸馏：高噪声训练、自蒸馏等减少动作专家调用次数的路线。
- 历史先验与热启动：历史进入生成源或初始轨迹，不等同于把历史拼接为条件。
- 自适应采样预算：按动作多模态/随机性调整步数，不能直接等同于环境动态调度。
- 异步执行与延迟补偿：以时间对齐、连续性和观测时效性为主要问题；流式方法可关联动作生成。
- 执行时序与动作粒度：缩短任务完成时间；不把这一收益描述成单次模型计算提速。
- WAM 与策略基座：记录世界分支与动作分支的耦合，以及训练/测试阶段是否需要未来生成。

同篇只录入一次。VLA、WAM、diffusion-policy 是标签/适用范围。记录某种方法用于特定基座，不推断其对所有 VLA 通用。

## 证据边界

条目保留论文版本、来源及评测设置。缺失配置标为“待补”，论文未说明的内容标为“未报告”。性能数据引用原文，复现实验另行记录。

记录版本固定链接，日期是事实核验日期。成功率、FLOPs、模型前向、完整本地策略调用、观测到执行延迟、任务完成时间分别保留；不同硬件与代码路径不做直接速度排名。完整流程见 [CONTRIBUTING](../CONTRIBUTING.md)。
