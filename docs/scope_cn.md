# 研究范围与分类依据

[返回首页](../README_cn.md)

## 研究范围

核心收录对象是为真实或仿真机器人输出可执行动作、动作序列或运动轨迹的学习式策略与动作模型，以及用于评测这些模型的基准。相关输出包括末端位姿、关节目标、底盘速度和力矩。

感知、人类动作数据、世界模型、仿真与传统控制可以作为基础资料收录，但应说明其与机器人动作生成或执行的联系。单独的纯感知或视频生成工作不属于核心收录范围。

## 分类边界与通用性记录

- **成果类型与研究方向：** 数据集、基准、模型和工具使用独立的 kind 字段，研究方向使用 category 字段。数据集论文可以包含采集装置和处理方法，按主要交付成果标为 dataset；不重复收录成多篇。末端归类依据采集／控制接口及实际验证，不能只根据标题中的 dexterous 一词判断为多指灵巧手。
- **数据集与评测基准：** 夹爪下的数据集入口收录 TacClaw-Infinity；灵巧手下统一设置“数据集与评测基准”，收录可复用数据、任务环境和评测协议。条目的 kind 字段继续区分 dataset 与 benchmark，触觉和采集方式作为标签。
- **三指等边界平台：** 结合独立可控自由度、动作空间和论文的主要研究问题判断，不只根据手指数分类。以整体夹持开合为主的平台可归入夹爪类；研究多指关节协同与接触调整的平台可归入灵巧手类。
- **其他末端：** 吸附及专用工具末端待有相关文献后再增设分类。软体／刚体是另外的结构属性，软体灵巧手不因材料柔软就自动归入“其他”。
- **通用性：** 分别记录跨任务、跨物体／场景、跨机械臂、跨末端形态的实验支持。“通用”或“跨本体”不单设为第三种末端形态。
- **操作共性方法：** 当主要贡献是可用于不同操作平台的方法时，按研究问题归入共性方法，并用标签和验证范围记录平台；它不是第三种末端形态。执行效率与时序控制关注任务完成时间，模型推理加速关注计算延迟，两者分别表述。跨基座验证不代表任意模型都可直接使用。
- **强化学习训练与探索：** 共性方法下收录主要贡献为课程学习、任务／起点采样和探索资源分配的可复用训练机制。SGS 以近期成功率选择预先构建的任务配置，改变训练时的重置分布，动作策略仍用 PPO 学习；它不生成新配置。记录配置池来源、成功率或价值估计的作用、最终执行策略和跨平台证据。SGS 同时验证夹爪装配与四足运动，按共性训练贡献收录；具体任务策略中的起点调度仍结合整体贡献归类，例如 DexMimic 保留在灵巧手动作策略学习。使用 RL 本身不构成本类归属依据。
- **机器人示范数据生成：** 主要产出是供机器人执行或训练的示范轨迹与数据。Gen2Dex 和 DexAgent 归在这里；视频恢复、重定向、RL 轨迹优化和仿真扩增是方法标签。在线操控的重定向控制器归策略与控制。区分示范生成、开环回放和下游闭环策略部署。
- **机器人操作策略与控制：** 按主要控制机制与贡献分为“动作策略学习”“技能学习与组合”“世界模型与规划控制”和“执行反馈与动作修正”。动作策略学习关注从观测学会生成动作，收录 No Eyes, No Problem、TTP 与 EgoJEPA；世界模型与规划控制利用动作条件预测搜索或选择动作，收录 DSP，交互采集与策略蒸馏作为方法记录；执行反馈与动作修正关注执行监控、修正与恢复，收录 AgenticTactileVLA。普通闭环观测本身不是归入反馈类的充分条件；含数据采集的完整规划控制框架不自动归入示范数据生成。EgoJEPA 通过人类视频预训练后适配机器人并直接生成动作，归动作策略学习；使用 WAM 并不自动归入规划控制，需有基于预测的动作搜索或选择。
- **技能学习与组合：** 主要贡献是技能发现／表示、技能间过渡、序列组合或完成判定与切换。DexStitch 归入本类，关联机器人示范数据生成；从人类视频学习、接触感知转换和扩散模仿学习作为方法记录。注明技能顺序来自视频、脚本还是自主规划；执行给定顺序不等于高层 Agent 自主规划。DexStitch 只验证固定四技能顺序，不能据此宣称未见顺序泛化；一般多任务策略若未研究技能结构或衔接，仍归动作策略学习。
- **双臂与躯干协同操作：** 在身体运动与全身控制板块收录通过双臂动作、躯干等上身支撑面完成抱持、换抱及物体转移的研究。WBD 归入本类；其“全身”指接触与操作范围，学习模型输出双臂 14 维关节目标增量，下肢与平衡由独立 AMO 控制器负责。分类不意味着策略统一控制所有关节；RL 专家蒸馏、扩散策略与指令细化作为展示标签。
- **验证范围列：** 简记已验证的末端与单／双臂配置、动作空间、泛化设置及是否需要微调或适配。区分模型设计目标与实验已验证的能力，未报告的项目写“未报告”。
- **跨形态工作：** 按主要贡献与核心评测选择一个主要分类，在验证范围中列全已验证形态，并用相关分类关联另一个分支。基准条目按其服务的评测对象归类。同一论文不重复编号。

- **任务与方法主题：** 手内操作、VLA、强化学习、触觉与接触反馈作为交叉浏览入口。按 tags 自动汇集工作，不改变主分类，也不复制论文。主题页注明匹配标签；使用或评测某方法不意味着它就是论文主要贡献。触觉与接触反馈同时涵盖传感触觉和基于本体信息的接触估计，具体区别见条目。首页与导图用最多三个双语 display_tags 直接展示主题和方法，完整 tags 保留在详情页。

- **Agent 架构：** 以运行时高层智能体与执行器的组织方式为入口。灵巧手下单列“Agent 架构”，与“机器人操作策略与控制”等分支并列，收录 RoboDexVLM、AdaClearGrasp、DexGraspVLA 与 GOTT；任务规划、技能编排、失败重规划作为标签，不设置对应下级分类。夹爪下按动作生成机制区分“Agent＋代码与工具”和“Agent＋学习式策略”：前者由 Agent 编程或调用工具明确指定运动目标，再由 IK、轨迹生成与控制器执行，收录运行时编程的 AGP 和上下文工具控制的 GPT-Policy；后者由 Agent 提供子任务、目标或操作条件，交给 VLA、WAM、扩散或 RL 策略等生成动作，收录 AR-WAM。仅感知使用学习模型不改变动作执行分支。上下文学习、运行时编程、经验复用及底层策略类型通过标签展示；两分支保留历史分类码与目录路径。反馈更新上下文不等于更新模型权重，工具执行检查不等于物理任务成功。记录任务如何转为目标／操作指令、规划与记忆在哪一层、何时返回反馈及如何恢复失败；WAM 等作为底层模型类型。本类包括高层语义／几何规划通过明确接口连接可复用低层技能的执行架构，以及依据执行结果更新后续步骤的反馈规划架构；逐篇注明高层重规划、低层闭环和固定阶段切换的边界。GOTT 按整体规划—技能执行架构归入本类，关联技能学习与组合、动作策略学习；其 Reach→Acquire→Move 为顺序执行，接触预测触发阶段切换，不据此宣称高层具备反馈重规划。底层技能与策略学习贡献通过相关分类和标签保留；仅使用 VLM 特征编码器或预设技能序列不足以自动归入本类。数据生成流程中使用 Agent 的工作，仍按其主要贡献归入机器人示范数据生成，不因使用 Agent 自动迁入本类。

- **人手动作与操作视频建模：** 以人手／相机轨迹和操作视频为对象，关注运动重建、未来预测和指令条件生成，作为灵巧手板块内的支撑研究。P³-WAM 放在这里，“统一感知、预测与规划”在论文标签中展示。机器人重定向和开环演示不等同于直接学习闭环机器人策略；与示范生成通过相关分类关联。

## 分类依据与相关综述

以下文献用于说明分类依据，暂不作为具体动作模型条目编号。第二层是本地图结合综述建立的检索结构；各综述的硬件、学习方法和模型功能分类不必共用一棵树。

| 综述 | 相关分类依据 |
|---|---|
| [Dexterous Manipulation through Imitation Learning: A Survey（2025 版）](https://arxiv.org/html/2504.03515v1) | 第 IV 节区分传统两指夹爪、多指仿人手和三指机械爪；第 III 节单独整理模仿学习方法，说明硬件形态和方法可分开组织。 |
| [A Review of Embodied Grasping（2025）](https://pmc.ncbi.nlm.nih.gov/articles/PMC11819895/) | 第 2.2 节讨论两指夹爪、灵巧手及其他末端；算法部分按具身感知、具身策略和具身智能体组织。 |
| [The Developments and Challenges towards Dexterous and Embodied Robotic Manipulation: A Survey（2025 版）](https://arxiv.org/html/2507.11840v1) | 第 III 节比较夹爪与多指灵巧手，后续分别讨论数据采集方式与模仿／强化学习框架。 |
| [Survey of learning-based approaches for robotic in-hand manipulation（2024）](https://www.frontiersin.org/journals/robotics-and-ai/articles/10.3389/frobt.2024.1455431/full) | 分别讨论基于模型的方法、强化学习与模仿学习，作为手内操作专题中方法标签的参考；这些路线可以组合，并非严格互斥。 |
